# Student Management System

A console-based Student Management System developed using C++.

## Features

- Add Student
- Search Student
- Update Student
- File Handling
- OOP

## Technologies

- C++
- File Handling
- OOP

## How to Run

Compile:

```bash
g++ main.cpp -o student
```

Run:

```bash
student.exe
```
